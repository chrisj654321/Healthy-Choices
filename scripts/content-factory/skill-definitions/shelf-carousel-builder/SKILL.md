# Shelf Carousel Builder

Only produce concepts whose ledger state is `concept_approved`.

## Workflow

1. Confirm the concept has one declared test variable and linked verified claims.
2. Use 3-7 slides only when the story requires them. Keep the hook immediate and the last slide useful.
3. Generate clean image assets through `higgsfield-generate` when needed. If people appear, use approved character references.
4. Obtain founder approval for consequential Higgsfield prompts before submitting generation jobs.
5. Never ask an image model to render wording. Put all text in the storyboard and let the local renderer place it inside safe zones.
6. Create distinct TikTok, Reels, and Shorts captions. Include AI and commercial disclosure notes when required.
7. Import concepts or produce approved work with `npm run content:produce`.

## Rules

- Warm, curious, practical, family-focused; never fearmongering.
- No logos or fabricated branded packaging without rights clearance.
- Do not make diagnoses, guarantees, or unsupported medical claims.
- Production does not approve, schedule, or publish content.
